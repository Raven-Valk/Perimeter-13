# Design documents

These came before the firmware. Their own numbering (pseudocode 1, 2, 3) is separate from the
firmware versions in this repository.

| File | What it is |
|---|---|
| `Pseudocode_1_first_draft.md` | The first pseudocode: states, login and lockout, sensor rules, tamper and maintenance, alert priorities, mapped to tests T01–T12. |
| `Pseudocode_2_review.md` | Review of the first draft against the specification and the parts list: hardware gaps, buy list, pin map, logic issues, revised pseudocode, test mapping. (Inside, the first draft is called "v1".) |
| `Pseudocode_3_two_node.md` | The two-node design (main controller + sensor node) that firmware v1 implements. |
